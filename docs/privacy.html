Política de Privacidad

Última actualización: 23 de julio de 2026

El proyecto Alfred no recibe, recopila ni comparte tus conversaciones o documentos. La inferencia y el almacenamiento operativo ocurren en tu dispositivo y no hay telemetría. La aplicación solo se conecta a Hugging Face cuando tú buscas o descargas un modelo.

1. Introducción

En Alfred, tu privacidad no es solo una prioridad, es el núcleo de nuestro diseño. Esta Política de Privacidad explica qué datos guarda la aplicación, dónde se almacenan y en qué casos realiza una conexión de red.

Alfred es un asistente de escritorio con inteligencia artificial completamente local. A diferencia de otros asistentes, no envía tus prompts, respuestas o archivos a un proveedor de IA. Con un GGUF local seleccionado, el chat no requiere conexión a internet.

2. Información que NO Recopilamos

El proyecto Alfred NO recibe, transmite a sus desarrolladores ni comparte:

  • Información personal identificable (nombre, email, dirección, etc.)
  • Documentos que procesas con la aplicación
  • Conversaciones con el asistente IA
  • Historial de consultas o búsquedas
  • Datos de uso o telemetría
  • Información del dispositivo o sistema operativo
  • Dirección IP o ubicación geográfica
  • Cookies o identificadores de seguimiento
  • Cualquier otro dato de uso de la aplicación

La aplicación sí guarda localmente conversaciones, configuración y logs para poder funcionar. “No recopilamos” significa que esos datos no se envían a los desarrolladores de Alfred.

3. Cómo Funciona Alfred

Inferencia y almacenamiento local

La generación de respuestas y el almacenamiento operativo ocurren en tu dispositivo:

  • IA local: el backend C++ carga modelos GGUF directamente con llama.cpp; no usa Ollama, Python, MCP ni una API de IA en la nube
  • Base de datos local: SQLite guarda conversaciones, memoria y configuración en el perfil de Windows
  • API local: la UI se comunica con el backend en 127.0.0.1:8000
  • Red limitada: Hugging Face solo se consulta cuando el usuario busca o descarga un modelo

Encriptación de Datos

El cifrado AES-256-GCM es opcional, está desactivado por defecto y requiere que el backend se haya compilado con OpenSSL:

  • Al activarlo, cifra escrituras nuevas de mensajes, valores de memoria y determinados campos de perfil; no cifra retroactivamente datos existentes
  • La clave aleatoria se almacena en %APPDATA%\Alfred\data\secret.key
  • No cifra modelos GGUF, logs, preferencias de UI ni todos los metadatos de SQLite
  • Quien obtenga la base de datos y la clave local puede descifrar los valores protegidos

4. Almacenamiento de Datos

Alfred almacena datos exclusivamente en tu dispositivo local:

  • Modelos: archivos GGUF descargados o copiados al directorio local de modelos
  • Historial de conversaciones: Tus conversaciones con el asistente, guardadas localmente
  • Memoria y configuración: ajustes de modelo, perfil y aplicación en SQLite
  • Documentos: rutas y metadatos de documentos cuando se usan esas funciones; el texto extraído de un adjunto se procesa como contexto local
  • Caché temporal: determinadas consultas sin conversación pueden mantenerse en memoria hasta que termina el backend
  • Configuración de usuario: Preferencias y ajustes de la aplicación
  • Logs locales: registros de diagnóstico. El backend puede incluir los primeros 80 caracteres de un prompt; el log de fallos de UI puede incluir mensajes y stack traces

Ubicaciones de almacenamiento:

  • Datos del backend: %APPDATA%\Alfred\ (AppData\Roaming)
  • Preferencias y fallos de UI: %LOCALAPPDATA%\Alfred\ (AppData\Local)

5. Conexiones a Internet

La aplicación puede conectarse a internet cuando tú:

  • Buscas modelos: el texto de búsqueda se envía a la API pública de Hugging Face
  • Descargas un modelo: el archivo GGUF se obtiene directamente de huggingface.co

Hugging Face recibe la consulta y los metadatos normales de red, como la dirección IP, bajo sus propias políticas. Alfred no incluye telemetría ni un verificador automático de actualizaciones. Con un modelo local, la inferencia funciona offline.

6. Código Abierto y Auditable

Alfred es software de código abierto bajo Apache License 2.0:

  • El código fuente está disponible públicamente en GitHub
  • Cualquiera puede auditar el código para verificar nuestras afirmaciones de privacidad
  • La comunidad puede contribuir y mejorar la aplicación
  • Las funcionalidades pueden contrastarse con el código publicado

7. Terceros y Servicios Externos

Alfred NO utiliza:

  • Servicios de análisis (Google Analytics, etc.)
  • Servicios de publicidad
  • Servicios de seguimiento o rastreo
  • CDNs para contenido dinámico
  • APIs de IA de terceros para generar respuestas

Hugging Face: La búsqueda y descarga de modelos es una integración directa y opcional. También puedes copiar un GGUF local en %APPDATA%\Alfred\models\ y evitar esas solicitudes desde la aplicación. Los enlaces externos que abras en el navegador quedan sujetos a las políticas del sitio correspondiente.

8. Control de tus Datos

Tienes control total sobre tus datos:

  • Eliminar conversaciones: Puedes borrar conversaciones individuales o en grupo desde la aplicación
  • Exportar conversaciones: Puedes exportarlas a Markdown; la base local usa SQLite
  • Eliminar todo: Cierra Alfred y elimina manualmente %APPDATA%\Alfred\ y %LOCALAPPDATA%\Alfred\. La desinstalación no garantiza borrar esos datos ni los modelos
  • Cifrado: Conserva secret.key mientras necesites leer filas cifradas; perderla hace que esos valores sean irrecuperables

9. Seguridad

Medidas de seguridad implementadas:

  • Host local: El backend administrado por la UI escucha en 127.0.0.1:8000
  • Token de sesión: Las rutas distintas de /health requieren un token aleatorio de 32 bytes en X-Alfred-Token
  • CORS restringido: No se publica un origen comodín para páginas web
  • Ciclo de vida: La UI mantiene el backend en un Job Object para terminarlo también ante un cierre abrupto
  • Cifrado opcional: AES-256-GCM protege los campos descritos anteriormente cuando OpenSSL está disponible

10. Actualizaciones de la Aplicación

Alfred no incluye actualmente un actualizador ni una comprobación automática de versiones:

  • Las versiones se publican manualmente en GitHub Releases
  • El usuario decide cuándo descargar e instalar una nueva versión
  • La aplicación no envía información del dispositivo para comprobar actualizaciones

11. Menores de Edad

Alfred no recopila datos de usuarios de ninguna edad. La aplicación puede ser utilizada por personas de cualquier edad bajo la supervisión de un adulto responsable cuando sea apropiado.

12. Cambios a esta Política

Cualquier cambio a esta Política de Privacidad será:

  • Publicado en esta página con fecha de actualización
  • Disponible en el repositorio de GitHub con historial de cambios

El uso continuado de Alfred después de cambios en la política constituye aceptación de los mismos.
